# שער איכות לפני פרסום

המסמך מגדיר את הבדיקות שחייבות לעבור לפני העלאה ציבורית. מטרתו להפריד בין בדיקות אוטומטיות הניתנות לשחזור לבין אישור חזותי ידני על חומרה אמיתית.

## שער אוטומטי

הרץ:

```bash
npm run verify
```

השער המלא כולל:

- חוזי Frontend,‏ JSDoc/`checkJs` וסמלי runtime לכל Route bundle.
- בדיקות Python וחוזי JavaScript.
- בניית Deploy נקייה ובדיקת תקציבי גודל.
- Playwright Chromium מול תוצרי הפריסה, לא מול קובצי המקור.
- מובייל, מקלדת בלבד, אחסון מקומי חסום וקטלוג גדול.
- חיפוש מהיר תחת האטת CPU פי 4 והוכחה שתוצאה ישנה אינה מצוירת.
- LCP, INP ו־CLS תחת פרופיל מובייל והאטת CPU פי 4.
- עצירת Job פעיל בלוח השליטה, חיבור מחדש לאחר רענון ושחזור העסקה.

התקציבים הנוכחיים לפרופיל `mobile4x` הם:

| מדד | תקרה |
|---|---:|
| LCP | 2500ms |
| INP | 200ms |
| CLS | 0.1 |

שינוי בתקציב חייב להיות גלוי ב־`performance-budgets.json`, עם הסבר בשינוי הקוד. אין לעקוף כשל באמצעות השבתת הבדיקה.

## סקירה חזותית ידנית על מכשירים אמיתיים

אמולציה בדפדפן אינה מחליפה מסך, מקלדת, GPU והתנהגות גלילה של מכשיר אמיתי. לפני פרסום יש לבצע לפחות את המטריצה הבאה:

| מכשיר | תרחישים |
|---|---|
| iPhone/Safari עדכני | בית, חיפוש, Viewer לאורך ולרוחב, מועדפים, חזרה מהיסטוריה |
| Android/Chrome בינוני | חיפוש מהיר, גלילה בקטלוג הגדול, Viewer, שמירה ומחיקה ממועדפים |
| מחשב Windows/Chrome | מקלדת בלבד, Zoom דפדפן 200%, Viewer, לוח שליטה ועצירת Job |
| מחשב macOS/Safari או Chrome | בית, חיפוש, Viewer ושיתוף |

בכל מכשיר בדוק:

1. אין חיתוך טקסט, חפיפה או קפיצה משמעותית בפריסה.
2. כפתורי Viewer נשארים נגישים ליד קצוות ומגרעת המסך.
3. פתיחת המקלדת אינה מסתירה את שדה החיפוש או את התוצאה הפעילה.
4. הודעת אחסון חסום אומרת במפורש שהשינוי זמני.
5. ניווט Back/Forward מחזיר לעמוד, לחיפוש ול־Viewer הנכונים.
6. סיבוב מסך אינו מאבד עמוד, Zoom או מוקד מקלדת.
7. קטלוג בן 100 עמודים ומעלה נשאר גליל ושמיש.

תעד עבור כל מכשיר: דגם, גרסת מערכת, דפדפן, תאריך, תוצאה והערות. פרסום מאושר רק כאשר אין תקלה חוסמת או כאשר קיים ויתור מפורש ומתועד.

## פרטיות ואמינות הודעות

- טקסט חלקי בזמן הקלדה אינו נשלח למדידה.
- מונח חיפוש שהושלם עשוי להישלח רק לאחר Enter או פתיחת תוצאה, עד 80 תווים.
- פעולת מועדפים מוצגת כ־“נשמרה” רק אם הכתיבה לאחסון אומתה.
- במצב אחסון חסום הממשק מציג שהשינוי קיים בזיכרון בלבד וייעלם לאחר רענון.

## אישור פרסום

רשום בסיכום הגרסה:

- מזהה Commit או SHA של החבילה.
- תוצאת `npm run verify`.
- תוצאות Core Web Vitals.
- רשימת המכשירים האמיתיים שנבדקו.
- תקלות ידועות והחלטה לגביהן.
